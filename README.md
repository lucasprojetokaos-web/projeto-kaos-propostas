# Propostas · Projeto Kaos

Cada proposta fica numa pasta própria e é publicada pelo GitHub Pages em
`https://lucasprojetokaos-web.github.io/projeto-kaos-propostas/<cliente>/`.

- `modelo/index.html` — modelo com as partes fixas preenchidas e as variáveis marcadas `{{...}}`
- `assets/` — CSS do design system, componentes, fonte Switzer e script de navegação
- `fotos/` — retratos em preto e branco de João Luz e Lucas Dato
- `<cliente>/index.html` — uma proposta por cliente

Todas as páginas usam `noindex`, mas o repositório é público: quem tiver o link consegue abrir.
